# QuickAccess DXB – Website (Fixed)

This is a clean Next.js 14 + TypeScript + Tailwind + shadcn/ui setup
for your QuickAccess DXB website.

## Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui style components
- Framer Motion
- next-themes

## Usage

```bash
npm install
npm run dev
```

Main routes:

- `/` – Home
- `/services` – services listing
- `/services/[slug]` – service detail
- `/projects` – project listing
- `/projects/[slug]` – project detail
- `/about`, `/career`, `/blog`, `/contact`, `/faq`
